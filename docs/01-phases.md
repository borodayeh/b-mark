## دو مورد که تضمین مطلق نمی‌دهم (و در README هم می‌نویسم)

1. **تک‌فایلی بودن مطلق EXE** — خروجی یک `B mark.exe` واقعی است ولی به
   WebView2 Runtime ویندوز وابسته است. رفتار برنامه در نبود آن: پیام
   دوزبانه + لینک رسمی. بدون دانلود مخفی.
2. **عدم تشخیص توسط آنتی‌ویروس** — با کد شفاف، عدم Obfuscation، Manifest
   استاندارد، اطلاعات Version/Company، و انتشار SHA-256 احتمال False
   Positive را کم می‌کنیم. تضمین نمی‌کنیم.
